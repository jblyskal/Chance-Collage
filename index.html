Collage dice

Roll one die per category. Each number picks an item from that category’s list. Build your collage from whatever comes up.

Edit the lists

Each category has six slots, one for each side of the die. Changes save in this browser.

“Save my lists as a new file” downloads a copy of this page (named index.html) with your current lists built in as the starting lists. Upload that file to replace the old one when you host it.
